# Dado

Lanzador de dado en el navegador, hecho con HTML, CSS y JavaScript y publicado con GitHub Pages.

**Web publicada:** https://gonzalo95md.github.io/dado/

## Qué hace

Muestra un dado y un botón. Al pulsarlo, genera un número aleatorio del 1 al 6 y lo muestra en pantalla.

## Tecnologías

- HTML: estructura de la página.
- CSS: aspecto y colores.
- JavaScript: lógica del lanzamiento del dado.
- Sin librerías externas.

## Cómo usarlo en local

1. Descarga o clona el repositorio:

        git clone https://github.com/gonzalo95md/dado.git

2. Abre `index.html` con doble clic en el navegador.

## Cómo se publicó

1. `git init` y primer commit en la carpeta del proyecto.
2. Repositorio público y vacío `dado` en GitHub.
3. `git remote add origin ...` y `git push -u origin main`.
4. Settings, Pages, Deploy from a branch, rama `main` y carpeta `/ (root)`.

## Actualizar la web

Cada cambio subido a `main` republica la página en uno o dos minutos:

    git add .
    git commit -m "Describe el cambio"
    git push
